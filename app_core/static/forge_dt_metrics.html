What this page shows, in plain words

The lab can apply a real fault or launch a real attack (Fault Injection / Attack Lab). The digital twin (Forensic Twin) watches the real nodes on its own, without being told what was tried. This page answers 4 real questions about that relationship, with real numbers instead of a single "detected / not detected" label -- and names every new building block it's built from, always explained below, never hidden behind a click.

Intervention LedgerA tamper-evident record of every real fault/attack applied in the lab -- what was tried, when, and whether it really worked. Chained with hashes so nobody can quietly edit history.
Effect VerifierConfirms a fault/attack really changed something real (a packet count, a file hash, a PLC value) -- never just "the script exited with code 0".
Experimental WindowA short, bounded burst of faster checks, started on purpose -- it never knows which fault/attack triggered it, so the twin's detection stays honest and blind.
Post-hoc LinkerAfter the fact, matches a real intervention to whatever the digital twin noticed on its own. Only used to grade the twin afterwards -- never consulted while it's detecting.
Evidence BridgeLinks a digital-twin alert to the real proof behind it -- a real file hash, a real new network port, a real PLC value. Never invents proof; links to it or says there isn't any yet.
CPR (Causal Path Recoverability)An existing platform score (0 to 1) for how much of the real attack's cause-and-effect chain could be rebuilt from forensic evidence after the fact. 1.0 = the whole chain was rebuilt; lower = some steps are missing.
WCPR (Weighted CPR)The same idea as CPR, but the more important steps of the chain count more -- missing a critical step hurts this score more than missing a minor one.

What "C0 → C3" means (shown further down this page)

These are NOT 4 different tests -- they're the SAME real campaign, looked at with 4 increasingly complete pairs of glasses. Each one is the previous one plus one more real thing added:

C0 -- just what already existedThe forensic reconstruction the platform already did before any of this work -- no digital twin involved at all. The starting point everything else builds on.
C1 -- C0 + the digital twinSame campaign, plus: every alert the digital twin raised on its own, without being told what was tried.
C2 -- C1 + the honest recordSame campaign, plus: compared against the real, tamper-evident record of what was actually applied and when (the Intervention Ledger) -- this is what lets us measure whether the twin really noticed it (IRR, TOR below).
C3 -- C2 + the real proofSame campaign, plus: each twin alert cross-checked against real preserved proof (a file hash, a new port, a PLC value) that confirms it's trustworthy (IER, ESR below).
