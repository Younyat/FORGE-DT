Host Memory Pressure Watchdog

Background watchdog running inside this host's own gunicorn workers -- watches swap% (and PSI when the kernel exposes it) every 20s. Above 80% swap it automatically runs gc.collect() and a safe drop_caches, the same actions as the manual "Free Host Memory" button above -- it never kills a process, never touches an active campaign job.
